# Python-Discord-Bot

1. Copy and rename the template ```bash cp .env.template .env```
1. Log into (Discord developer portal)[https://discord.com/developers/home]
     - a. Click on 'Applications
     - b. Create a new application, then/or
     - c. Open your application
1. Navigate to Bot
1. Reset the bot token
1. Copy and paste the token into .env as DISCORD_TOKEN
1. Enable 'public bot'
1. Enable your intents
1. Navigate to OAuth2 > OAuth2 URL Generator
1. Scopes
     - check `bot`
1. Bot permissions
     - select your permissions
1. Select Integration type
1. Copy the generated URL
1. Paste into browser
1. Install into your server
