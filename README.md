# Jade's D20 Reference Bot

## Bot Commands

All commands use the prefix `//`.

### Dice Rolling
- `//roll NdN`  
- Aliases: `//Roll`, `//ROLL`
- Rolls dice in NdN format (e.g., `//roll 2d6`).  

### Role Lookup
- `//role <class name>`  
- Aliases: `//Role`, `//roles`, `//Roles`
- Provides a link to reference for a FutureD20 class (e.g., `//role Ambassador`).  

### Cybernetics Reference
- `//cybernetics`
- Aliases: `//augmentation`, `//augmentations`
- Provides a link to the Cybernetics Reference.

### Expanded Skills Reference
- `//futureskills`
- Provides a link to the Expanded Skills reference.

### Expanded Skill Commands
- `//bluff`
- Provides the Bluff expanded-skill link.

- `//computeruse`
- Provides the Computer Use expanded-skill link.

- `//disabledevice`
- Provides the Disable Device expanded-skill link.

- `//knowledgetechnology`
- Aliases: `//knowledgetech`, `//techknowledge`
- Provides the Knowledge (Technology) expanded-skill link.

- `//navigate`
- Provides the Navigate expanded-skill link.

- `//pilot`
- Provides the Pilot expanded-skill link.

- `//futurerepair`
- Alias: `//repairfuture`
- Provides the Repair expanded-skill link.

- `//treatinjury`
- Provides the Treat Injury expanded-skill link.
